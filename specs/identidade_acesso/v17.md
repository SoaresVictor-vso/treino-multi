## Alteração

As chamadas do navegador à API passam pelo proxy same-origin `/api` do Next.js. O refresh token continua em cookie `HttpOnly`, mas agora é first-party do domínio do front-end e usa `Secure` e `SameSite=Strict` tanto em desenvolvimento como em produção. O cookie usa o caminho `/api/auth`. Requisições server-side que precisam acessar diretamente a API usam `NEXT_PUBLIC_API_URL` como origem do backend.
