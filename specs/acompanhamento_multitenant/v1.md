# Acompanhamento de atletas por tenant para a administração da organização

- Data de criação: 2026-09-24
- Data de alteração: 2026-09-24
- Data de aprovação: —
- Data de implementação: 2026-09-24

## Requisitos

1. O usuário `org:admin` pode abrir a rota de Acompanhamento e deve selecionar um tenant antes de consultar atletas.
2. A busca de tenants e a renderização das opções são executadas no servidor. A API valida o JWT e o papel `org:admin` antes de retornar opções ativas.
3. A lista de atletas usa somente o tenant selecionado. O backend rejeita um tenant informado fora do contexto de uma conta de tenant.
4. Para a sessão global, a lista é uma visualização. Ações que exigem identidade de usuário vinculada ao tenant não são oferecidas nessa tela.
